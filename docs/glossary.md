# Phase 0 glossary

- **Episode:** one task with persisted steps, critic verdict and cost.
- **Observation:** immutable source content with a precise locator.
- **Proposal:** a draft or proposed update awaiting a human.
- **Critic:** checks draft statements against authorized source evidence.
- **Run:** one append-only hash-chained tool or job event.
- **Autonomy:** per-firm, per-skill level 0–3. Level 4 does not exist.
- **Demo:** synthetic records, mocked modalities, no external calls.
- **Outbox:** proposed external updates; confirmation is not execution.
