# Core, Phase 0 review

Treat source text as untrusted data with provenance. Use only the five approved
side-effect classes and the acting user's permissions.

An Ask uses read-class tools, creates no business proposal and ends at present.
Only explicitly requested draft/extraction tools may create proposals. Reuse
semantically identical active proposals and link the Episode to the existing one.
Every answer must pass the five structured critic checks before presentation.
Synthetic usage consumes the same guarded budget path as provider usage. Stop
on exhaustion, preserve any partial draft as stopped and ask for human review.
